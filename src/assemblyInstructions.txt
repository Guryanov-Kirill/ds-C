ШАГ 1: Компиляция с-кода

gcc -c application.c -o application.o

-c - означает, что выполняется только компиляция, без линковки.

-o application.o - выходной файл


ШАГ 2: Компиляция ассемблерного кода

gcc -c sort.s -o sort.o

создаётся файл sort.o с ассемблерным кодом, преобразованным в машинный.

ШАГ 3: Линковка

gcc main.o sort.o -o sorter
